# Windows 安装包

[下载知页 Windows 免安装版](https://github.com/xucong78/11/raw/refs/heads/main/downloads/zhiye-windows-x64.zip)

适用 Windows 10 / 11，64 位 Intel / AMD 电脑。已包含官方 Node.js 运行环境。

1. 下载 `zhiye-windows-x64.zip` 并完整解压。
2. 打开解压后的「知页」文件夹。
3. 双击 **启动知页.bat**，默认浏览器会打开工作台。
4. 使用期间保留启动窗口，关闭窗口即可停止。

可直接使用示例模板、编辑知识卡片、保存作品和导出高清图片。生成新选题需要在界面中配置模型服务。当前版本没有接入抖音自动发布。

安装包完整性校验见同目录 `zhiye-windows-x64.zip.sha256`。运行环境来源与 SHA-256 写在压缩包内 `portable.json` 中。云端已验证启动和导出流程，尚未在 Windows 实机测试。

# 粉商小本 · 达人带货商务 SOP 与工具包

食品商家达人短视频商务的通用试运行模板，覆盖找达人、谈合作、寄样、内容排期、发布验收与成交结算复盘。

**[下载完整工具包](https://github.com/xucong78/11/raw/refs/heads/main/downloads/creator-bd-starter.zip)**

完整解压后，双击 **达人商务工作台.html**。无需安装 Node.js，不需要服务器或模型密钥。首次打开是空台账，演示数据需手动载入并有明确标记。

## 工具包内容

- **达人商务工作台.html**：今日待办、合作管线、负责人及下一动作、寄样 / 发布检查、报价保本、SOP 清单、JSON 备份与 CSV 导出。
- **SOP阅读版.html**：完整流程、责任分工、输入输出、完成标准、D1–D5 与30天试点计划；浏览器可打印。
- **SOP.md**：可编辑的原始文档。
- **达人带货商务台账.xlsx**：8页空白台账及独立示例，涵盖业务字典、达人合作、寄样、订单与视频、报价、每周漏斗和使用说明。
- **先看这里.txt**：打开方法、第一天资料清单、数据备份和适用范围。

模板没有公司真实经营信息，不预设真实佣金、价格、利润或公司 KPI。填写的达人、报价和成交数据仅保存在本机，不会自动上传 GitHub。工作台与 Excel 独立，不自动同步；正式使用时应明确主台账。

工具不自动抓取抖音、不自动发送消息、寄样、付款或发布。它辅助跟进与记录，不代替公司审批、官方后台与财务结算。

## 验证

网页已验证9组业务场景，包含授权、寄样、视频链接、去重、筛选、逾期、JSON 恢复、CSV 和测算边界；手机布局已检查。Excel 通过结构及边界校验、25项 LibreOffice 实际重算。当前云环境管理策略限制 `file://`，网页功能用原样 HTML 的本机 HTTP 夹具验证；尚未在 Windows Excel/WPS 或 Windows 双击场景实机验证。

在仓库根目录安装开发依赖后，浏览器检查命令：

```bash
node --test tools/creator-bd/tests/browser-check.mjs
```

可通过 `CHROMIUM_PATH` 指定系统浏览器。生成 Excel 需要 Python 的 `xlsxwriter`，然后运行同目录 `generate_workbook.py`。日常使用现成 HTML 与 XLSX 无需这些开发工具。

## 后续迭代

先用一小批真实合作校准字段、节奏和口径，再确定是否需要多人协同、企业权限、提醒、订单导入或平台接口。实际公司数据应放在公司允许的位置。

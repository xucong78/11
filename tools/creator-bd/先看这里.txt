粉商小本 · 达人带货商务 SOP 与工具包

这是一套通用试运行模板，不含任何公司的真实经营信息。
适用：对接食品带货达人、谈合作、寄样、跟进视频发布和成交的商家商务。

一、怎么打开

1. 将整个压缩包完整解压到固定文件夹。
2. 双击「达人商务工作台.html」，用 Edge 或 Chrome 打开。
3. 不需要安装 Node.js、配置服务器、填写模型密钥或联网登录。
4. 点击工作台中的「阅读完整 SOP」，或直接打开「SOP阅读版.html」。
5. 「达人带货商务台账.xlsx」可用 Excel / WPS 打开。它是独立台账，不会与网页自动同步。

二、第一天先做什么

先与直属负责人确认六类资料：
- 商品：SKU、规格、标签、配料与过敏原、保质和食用方法、可以对外使用的证据资料。
- 生意：价格、活动、库存、发货、运费与售后承接。
- 费用：成本、计佣基数、佣金、固定费、样品物流、付款和审批权限。
- 资源：历史合作达人、正在对接的人、已寄未发、待结算与排重规则。
- 数据：后台权限、归因和观察窗口、有效订单、退款与结算口径。
- 分工：谁能决定价格与预算，谁处理物流、内容、售后与财务异常。

未知字段保持「待确认」，不要用 0 代替未知，也不要先承诺未经批准的价格或佣金。

三、离线工作台怎么用

- 今日待办：根据下次跟进日期，查看今日与逾期事项。
- 合作管线：每条记录一项合作 / 一个视频，必须有负责人、下一步和日期。
- 报价测算：输入已核实的收入成本口径，估算单均贡献与保本有效订单数。
- SOP 清单：逐项核对准备、筛选、合作、寄样、发布和复盘。
- 导入与备份：每天导出 JSON 留存；CSV 只用于查看，不作为恢复备份。

寄样及后续节点需要手工确认公司授权；已寄样需填写快递或记录，已发布需填写视频链接。
这些是辅助提醒，不是公司的真实审批系统，也不会核实你填写的授权是否有效。
工作台的「复盘完成」仅指复盘记录完成，对账、付款与结算需继续使用公司系统或 Excel 台账。
同一达人多条视频分别记录，避免把同一批订单在不同观察窗口重复计入。

四、保存数据要注意

网页数据保存在当前浏览器的本机存储中，不会上传到 GitHub。
清理浏览器数据、使用隐私模式、换浏览器或移动网页文件，都可能让旧数据无法直接读取。
请定期导出 JSON，放到公司允许的位置；导入备份会替换当前数据，请先导出当前台账。
Excel 与网页不自动合并，正式试运行时请明确哪一个是主台账，不要两边重复维护不一致的数据。

只记录必要的联系方式与证据位置；完整收货地址、身份证、账号口令等放在公司授权系统，不写在这个工具里。
演示数据带有标记，正式使用前先清空。示例不代表真实达人、售价、利润、佣金或业绩。

五、建议的落地顺序

D1：确认资料、权限、口径和历史合作；先清点已有进行中合作。
D2：建立 SKU 合作卡与达人筛选标准，录入一小批代表性合作。
D3：按统一确认单推进沟通、预算与寄样，补全每项合作的下一步。
D4：把签收、体验、内容和排期的阻塞点跑一遍，明确异常找谁处理。
D5：做第一次小复盘，调整字段与提醒节奏，再确定日 / 周目标。

完整步骤、完成标准、责任人和30天试点方案见 SOP阅读版.html / SOP.md。
SOP 中的提醒节奏是试运行建议，不是平台规定，也不是未经达人同意的合作条款。

六、测试与适用范围

工具不自动采集抖音数据，不会自动发送私信、寄样、付款或发布内容。
网页功能在桌面与手机浏览器的本机 HTTP 测试环境验证；当前云环境对 file:// 有管理策略限制，未直接验证 Windows 双击打开。
Excel 的公式经过 LibreOffice 重算验证，未在 Windows Excel / WPS 实机测试。
如果公司电脑限制打开本地网页，请交给本地 Codex 在本机临时启动静态网页服务，不要关闭公司的安全策略。
此版本适合先做个人试运行；多人协同、企业级权限、服务端同步和平台数据接口需要后续明确需求再开发。
